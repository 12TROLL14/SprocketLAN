# SprocketLAN
Sprocket LAN Multiplayer mod using BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.780+3be4532

If you don't know how to install this mod, just ask ChatGPT i'm sure it'll gladly guide you :)

This mod was developed with the assistance of the Universal Modder toolkit.
Despite being a LAN only mod, can be used over the internet with the help of software like LogMeIn Hamachi, Radmin VPN, Zero Tier One or similar.

To use this mod,

set TargetIp to the host's IP in the config (appears in BepInEx\config after first launch)

set IsHost to false (appears in BepInEx\config after first launch)

both players need to have the blueprints of all the tanks taking part in the match

start a custom battle, put the tank you want to use on the player team and the other player's tanks in the AI team.

ensure all players use the same map.

Launch the custom battle

press f9 to open the mod menu

press f10 to host a match

ensure your tank is not in the same location as someone else's before joining

press f11 to join a match

press escape then click on reset to respawn.
